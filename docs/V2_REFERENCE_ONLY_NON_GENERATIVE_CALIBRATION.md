## Governing decision

**Photo Finish does not perform generative photo editing.** The four source/reference pairs are not one uniform category. The **sky pair is a positive natural-looking tone reference** (`POSITIVE_NATURAL_REFERENCE`, user judges cloud shapes and airplane light points to correspond to the original; production provenance unverified). The **street, antique-sign alley and waterfront-night references are three negative overprocessing examples** (`NEGATIVE_OVERPROCESSING_REFERENCE`, suspected generative/content changes; exact per-file provenance not independently verified). Style observations may inform *brightness distribution, saturation, warm–cool relationships and shadow hierarchy only*; reference pictures are never content targets, production output, actual edits, or accepted V1s. Neither category confers Stage 0/1 approval.

Never upload private source/reference photos, hashes identifying user files, Library IDs or local paths into the public repository or public release package; the exact private identities belong only in the user's private sample manifest.

### Measurement rules

1. Keep the existing Stage 1 metric definitions: encoded sRGB `L = 0.299R + 0.587G + 0.114B` (a display-encoding proxy, not linear luminance), P01/P50/P99, chroma-radius, highlight headroom, semantic ROI warm/cool, local 8×8 texture/contrast, P05 shadow and near-black counts. Honor actual input ICC through color conversion; references missing ICC are assumed sRGB for **descriptive statistics only** and explicitly flagged.
2. An unregistered crop/scale or changed object means no valid same-pixel difference, SSIM, 1:1 source-reference attribution, content-mask comparison, or reference-driven target numeric threshold. Global distributions may be reported descriptively but can be biased by new/generated content and must not be optimized blindly.
3. Register each pair with two separate lists: `bounded_editing_calibration_dimensions` and `excluded_reference_content`. Plan source-supported adjustments only; if an effect in the reference depends on imagined clouds, lettering, building detail, synthetic sky or reflections, mark it **NOT_REPRODUCIBLE_AS_NON_GENERATIVE_TARGET**, not a shortfall of current bounded-curve strength.
4. The user may choose a style direction without accepting the reference image as an output. Reference-only membership **does not count** toward the eight independent, genuinely edited samples or historical photography GO. Source originals may later join the eight-photo corpus only through a separately authorized, source-bound, non-generative real task.
5. Freeze source/actual-candidate source hashes, original-source ROI and user-protected text/geometry before editing. The reference can influence color/tonal priorities but never define the allowed content changes or masks.

No claim about reference-image rendering intent or provenance follows from these numbers. Read-only reproduction script, source/reference hashes, and detailed table remain private.

**Retained naturalness prompts (review hints only):**
1. **Deeper shadows:** compare source-registered dark ROI encoded-sRGB `L` P05 and `L≤5` / `L<30` proportions; intentional deep shadow is not automatically overprocessed.
2. **Texture exaggerated or suppressed:** inspect the same-source, same-scale 1:1 ROI (local gradients and contrast plus visual examination); no exact correspondence is inferred from unregistered R.
3. **Content absent from the source:** compare camera original S against actual non-generative controller output C, especially letters, buildings, clouds and meaningful reflection structure. Newly observed content is a human-review signal; existing preservation/STOP obligations remain intact.

### Draft: structural-fidelity check of S versus C (advisory only; no GO, no new engineering gate)

- Use a source-bound, geometrically registered **camera original S and actual controller result C**. Verify source/output hashes, ICC, orientation, dimensions and any declared crop transform; only compare genuinely overlapping 1:1 ROI. **Generated/reference image R is excluded from this check.**
- Convert each embedded ICC to sRGB and compute the same encoded 8-bit luminance proxy `L=.299R+.587G+.114B`. Compare 3×3 Sobel gradient direction and magnitude and the locations of bright/dark intensity edges. Report candidate strong-gradient locations unsupported near source gradients as **areas to inspect**, not automatically invented content.
- For a fixed *descriptive sampling slice*, take the top 5% gradients in each image independently and allow a ±2 px spatial tolerance. Report C→S/S→C edge position overlap, unmatched strong-gradient fraction, P95 gradient magnitude ratio, and gradient-direction cosine for exact same-position strong edges. **The 5% percentile slice and ±2 px matching radius are measurement definitions, not thresholds for GO/NO-GO.** A real contrast curve may strengthen source edges without changing any physical structure.
- If S and C were legitimately reframed, establish a verified coordinate transform before computation; if not, report no comparable structural result. This procedure cannot prove content hallucination or authenticity, and it does not run as a new native-controller quality gate.

## Stage 5 — acceptance comparison and content-change exclusions

For every true real-photo trial, use **three distinct, non-substitutable identities**:

- **S:** authentic camera-original photograph, source SHA/ICC/orientation and protected semantic content. This is the sole source-of-truth for structure, text, architecture, sky objects and natural texture.
- **R:** reference-only style image, possibly generative. It is never the controller result and contributes no content truth. If an approximate original-scene region can be verified, a qualitative/aggregate tonal comparison may be made after noting crop/color-space differences. Otherwise do not compare it as an exact target.
- **C:** actual output from the verified **non-generative Photo Finish controller**, with source and output receipt, complete SHA, PNG/ICC and same-source ROI evidence. Only C may be submitted for real candidate inspection and user GO/NO-GO.

**Exclude** from S/R style scoring only the reference's flagged content deviations: backlit-street new clouds and road-sign lettering **[observed]**, antique-sign lettering **[observed]**, night canvas expansion **[observed]**, plus any specifically noted **[suspected / pending verification]** changes (such as alleged nighttime building lights/reflections). **Do not assume the sky reference invented clouds or texture.** Incompatible or unpaired pixels are **not scoreable**, not a negative result and not an invitation to reconstruct them. Do not compute content-weighted similarity to R or ask whether C copied its novel objects. Any acceptance statistic must state the exact valid source-based region, any excluded region and the reason; non-overlapping night compositions have no valid 1:1 S–R score at all.

**Do not exclude real C content failures.** Changes to source-sign text, fixed architecture, critical objects, real sky features or substantive reflections **in Photo Finish's own candidate C** remain ordinary **failure/STOP** against S; they are never excused by being present in R. The actual source-to-controller-result technical gates (source SHA, ICC, dimensions under the declared non-generative crop operation, mask bounds, signed-off protected ROIs and visible 1:1) remain fully applicable.

**Stage 5 / Stage 6 blinded viewing response:** preserve the existing choices “A 更好”, “B 更好”, “相当”, “不确定” and add a distinct fifth choice **“看起来像 AI 生成”**. This is a user-observed visual-naturalness signal; it is **not** model provenance proof or automatic engineering GO/NO-GO, and it does not count as a candidate win. Continue comparing true C against S, never whether C copied R's novel objects. Record 1:1 and source identity separately.

Stage 5's eight authentic photographs, any 2–3 designated difficult scenes and user blind testing retain their existing independent gates. **Stages 0 and 1 remain PENDING_USER_CONFIRMATION, not GO.** These four **reference pairs contribute zero accepted edits** to the eight; a camera-original that is later separately edited may contribute one genuinely independent trial at most. Historical river/building/Church/Wynn GO and night NO-GO retain their precise prior meaning; generated examples cannot reverse them. No automatic strength threshold or new editing technology is implied by this documentation.
