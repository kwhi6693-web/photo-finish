## 区域能力核查

实际使用的 imagegen 参数只有提示词、参考文件和背景等，没有区域遮罩或非目标原像素锁定接口。此前失败有实际全幅/原生细节对照，并非仅参数推测。

现有 Adobe 工具描述另提供 selection 和 maskURI 局部调整接口，但本轮仅核对了接口，未建立当前 V1 的可访问输入、生成并实际检查遮罩或取得局部编辑输出；不能据接口存在宣称已能保护树冠/远山/草地/围栏，也不能宣称所有宿主均没有遮罩能力。没有擅自增加付费服务、API key 或图像后端。必要能力未验证前维持局部实修失败状态。
