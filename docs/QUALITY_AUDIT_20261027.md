## Current tool capability audit

Inspected the exposed tool definitions in this engineering session; no image tool was invoked.

| Route | Declared available interface | Safe execution / limitation |
|---|---|---|
| Native global | Adobe image_apply_adjustments: tonal/color controls, imageURIs, PNG output. | Actual input preview before every call; authorized route only. Interface visibility does not prove task success, detail recovery or correct ICC. Combine compatible controls only when photographic order permits. |
| Native region | Adobe selection tools return mask output; image_apply_adjustments takes top-level maskURI. | A single positive scene target; invert negative-space selections per tool contract. Review real mask against current source, including holes, hard/feathered boundaries and changed/removed selections. No reliable leaf/text-level precision guarantee. |
| Generative | imagegen full-frame reference edit is exposed separately. | Necessary creative generation only, with content protection. Current interface has no verified region-mask argument; blocked for local-only revisions. Adobe selection does not itself provide generation. |
| Unsupported/blocked | Missing valid source/mask/output, unknown local editor, authorization/STOP or tool failure. | Keep accepted parent/original. No repeated prompt-only full-frame retries, code-simulated edits, inferred success or silently substituted version. Unknown calls are investigated first. |

Mask existence is not mask quality; zero changes in a few protected rectangles are not a whole-mask exclusion certificate. Even proven outside-mask equality does not establish improvement inside the target. A URL argument is not proof of accessible or source-bound mask bytes.

## Five-scene quality acceptance matrix

Every new sample checks six axes separately: naturalness, native detail, structure, light/color, user constraints and delivery. Accepted/rejected/unmeasured are explicit; there is no universal pass score or mandatory edit count.

| Scene class | Actual historical evidence retained | Required scene-specific review before a new pass | Current gap |
|---|---|---|---|
| Natural/backlit landscape | Forest generation failed native-detail review; actual masked native sky attempt preserved outside-mask pixels but failed useful/complete local improvement. | Check coherent light direction and space; backlit haze versus defect; branches/grass/cloud texture; canopy sky holes and horizon halos; selected crop/creative changes; original and accepted-parent identity. | Complex sky transitions and new useful improvement pending. |
| City night | Native component evidence; generated visible sign lettering rejected. | Preserve night mood, highlight/light-source color separation, signage/strokes, architecture and incidental identities; distinguish motion blur/noise from invented detail; no crushed subjects or default HDR. | Broad city-night full host/delivery certification pending; do not equate a component pass with a complete task. |
| Architecture + text | [Host report](HOST_CAPABILITIES_20261026.md) records native formal PNG delivery and later selected-sky softening with unchanged checked structural/text regions. | Compare readable letter shapes, pipes/roof lines/perspective and material; check every affected boundary and current source/mask; avoid invented letters and repeated texture. | Historical local mask was not exported for independent whole-mask certification; new branch not visually tested. |
| Travel landscape batch | [Three-photo travel acceptance](TRAVEL_BATCH_ACCEPTANCE_20261026.md): real native outputs, per-file save/readback/version evidence and controlled local-file fault isolation. | Per-image light, white balance and intent; series coherence without identical sliders; preserve original order, independent errors and completed-item deduplication. | No real external-provider outage certification or new batch run. |
| Soft/low-exposure landscape | [Scoped review](SCOPED_RELEASE_REVIEW_20261027.md): atmospheric forest was not established as defective; attempted native output rejected for insufficient benefit. | Distinguish intentional low key, mist, motion and optical blur; inspect shadow color/noise, highlight headroom and texture at native scale; reject halos, crunchy sharpening and fabricated restoration. | Authorized genuinely improvable sample and optical-defocus recovery evidence absent. |

For an already accepted image: revise from the selected version, compare target and non-target areas against that exact parent, preserve original/parent records, and register another version only after real improvement and required save evidence. If the tool cannot supply an effective mask, preserve the parent and stop that edit.
