# Photo Finish 2.0 — 单次完整升级验收契约

状态：**Draft / NO-GO**。本文件是验收与阻断依据，不是发布证明、安装记录或扩大工具权限的授权。

## 唯一交付目标

完成后，用户上传具有使用和编辑授权的非人像原片，Photo Finish 应在一次正常任务中：
1. 读取当前个人风格与授权参考，实看原片、确定摄影主题、空间叙事与是否真正需要编辑。
2. 在真实可用工具中选择**能够保持原始场景高度相似**的编辑路线，预先检查重要文字、建筑、物体、自然纹理与边缘；不能用完全新生成的布景代替用户原图。
3. 完成真实编辑，首张正式成片尽量达到成熟的自然、克制且有明确光影表现的专业摄影效果；优秀原片可有依据地不编辑。
4. 在聊天中**直接显示真实的成片图片**，可在 iPhone「照片」App 保存。不强制通过 Adobe 页面或让用户自行编辑。
5. 在文件与实际验收允许的范围内完成真实来源、正式 V1、可靠保存、零渲染版本恢复与跨会话取回。缺少权威回执时只记录待确认，绝不假称保存或恢复成功。

## 必须全部通过的发布门禁（逐项实际取证）

| 门禁 | 必需的可核验证据 | 失败或 STOP |
| --- | --- | --- |
| 源与隐私 | 原片 SHA-256、方向、真实 ICC；个人风格库只读；公开包不含任何私人照片、标识或历史账本 | 原片不一致、私密资料泄露即 STOP |
| 工具路线 | 实际调用经过验证的非生成式编辑工具；生成式参考图仅可用于影调与色彩校准，不得作为编辑输出或内容目标；保护目标与实际工具能力匹配，局部编辑有同源蒙版 | 非生成保留目标调用整图生成、选区漏选/误选而继续即 STOP |
| 摄影质量 | 真实原片↔真实输出在正常观看和 1:1 细节对照；主体、前中后景、明暗、色彩、材质、叙事明显改善；记录艺术判断与接受/拒绝原因 | 原片优于成片、假光晕、文字损伤、肤色/人像美化或偏离场景即拒绝 |
| 多样场景 | 首轮至少 3 张不同类别非人像；成熟后扩大到多景别、混合光和建筑边缘，且避免同一原片的重复版本冒充独立样本 | 不能从单张照片或 synthetic 回归外推整体质量 |
| 真实输出 | 输入输出同源；原生成工具输出的 URL、预览 JPEG 与原生最终文件身份区分；本地无损 PNG 必须完整解码、校验像素与实际 ICC | 预览代替正式字节、同源关系不可确认即停止对应工程门禁 |
| 用户端直接交付 | 真正编辑的图片直接显示在 ChatGPT，用户实际验证可在 iPhone「照片」App 保存 | 只有 Adobe 预览或文件链接不能谎称原生体验通过 |
| 版本恢复 | 真实 source/output/save_receipt 与 V1 索引对应；独立跨会话取回同一文件 SHA-256；恢复零渲染且不修改其他版本 | 没有权威回执仅为待确认，不能私造 V1 |
| 工程回归 | 同一最终提交的 6 项 Windows/macOS/Linux CI 全部绿灯；所有新回归、来源链/安全/文件格式/回滚测试通过 | CI 失败不得绕过检查 |
| 发行完整性 | v2.0.0 一致版本、真实 Skill 入口与同步哈希、可复现正式 ZIP、Manifest、公开附件 SHA-256 校验 | 不得覆盖或更改旧版发行包 |
| 一次性替换 | 保留当前主用版本完整恢复快照与私人风格资料，安装 v2.0.0 后真实读取安装版本并 iPhone 保存验收；有可执行回滚 | 宿主安装失败/字节被替换/缺备份均 NO-GO |

**特别区分：** 使用者确认某一张真实照片可直接保存，是这张照片的**交付 GO**；不能自动升级成 Photo Finish 2.0 的整体工程、摄影质量和发布 GO。Adobe 原始 PNG 在另一条已证明真实可用、可追溯的原生图片输出路线下，不构成每次日常修图的独立刚性条件；但正式保存/恢复所需的同一真实文件哈希及回执不允许跳过。

## 待验证高影响问题（不是本轮已经解决）

1. `experiments/v2_local_light` 尚须在不依赖预览或占位布尔声明的前提下接入可执行生产路径；本地输出候选文件不能自认证正式 V1。
2. 自动语义选区曾漏掉静物陶器、把天空误选为教堂，需要实图蒙版检查与结构保护。
3. 城市夜景的色带、噪点；建筑/树叶边缘光晕；庭院小改无明显表达增益：均为真实失败样本，不能用更多 synthetic tests 结案。
4. 个人风格库、正向审美反馈和首张成片的摄影表达需要在真实任务中闭环，不能只靠规则文本。
5. 本轮已实测 iPhone 保存和 Library 同会话零渲染取回的是**本地非 Adobe PNG**；并非 Adobe 编辑的同一份文件，也不是 v2 控制器端到端正式恢复。
