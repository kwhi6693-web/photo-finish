# Photo Finish 长期产品定位

Photo Finish 是面向非人像摄影场景的专业照片美化 Agent Skill，主要支持自然风光、城市夜景、建筑、旅行场景、静物、美食和产品摄影。该定位属于产品规范，不是从单次反馈推断的私人偏好。

- 不开发人脸美化、磨皮、塑形、五官调整或针对性肖像优化，不处理以人物为主体的人像照片。
- 正式视觉验收不使用人像照片，不将人像处理效果作为质量指标。已有合成协议测试中的 people/identity 目标检验通用保护契约，继续保留，不代表人像修图能力或人像效果验收。
- 非人像照片偶然有人物时，保持必要的身份、结构和内容保护，不进行针对性人物美化。
- 优先优化自然纹理、光影、色彩、构图保护、风格一致性和真实细节。生成纹理不能称为真实细节恢复；提示词不能证明质量或局部保护成功。
- 保留原片与参考哈希、锁定保护契约、真实图像复核、未知状态不重发、历史不可变、保存回执和安全恢复机制。
- 个人风格库、自定义指令、专业理论、批量处理和版本操作沿用现有架构。能力范围不等于各场景均已真实验收通过，未验证项继续如实记录。

收到适用非人像照片时沿用自动 EDIT_TARGET 流程；不增加前置模式选择。用户请求人像专门处理时简短说明范围，不提交人像修图。维护与发行继续经现有开发分支及 Draft PR 审阅。
