Photo Finish 2.0 WP3 pre-edit source-bound composition planning (Draft PR #47 only).

After actual user editing permission and assistant/human inspection of original non-portrait pixels, record private frame observation with actual camera_original_sha256 and source_sha256, observation_origin, original_visually_inspected=true, nonportrait_scope=true, generative_edit_requested=false, photographic_intent and visual_observation based on the actual source. Select frame_action=keep (source_bbox_px=null) or frame_action=crop with crop_visually_inspected=true, exact original source_bbox_px and two or more reviewed_must_keep_boxes labeled with source pixel rectangles. This module never perceives an image by itself. It rejects unreviewed crop, missing source identity, invalid coordinates, cuts through protected rectangles, or output smaller than the existing 64-pixel technical engine minimum. It imposes no mandatory percentage, aesthetic crop or output-resolution limit; full-frame no-op proposals return KEEP_FRAME. Actual content coverage and final photographic benefit require independent real-image review.

Run via native launcher: v2_native_entry plan-frame ORIGINAL LINEAGE.json FRAME_OBSERVATION.json FRAME_DECISION.json. KEEP_FRAME means preserve composition, not RETAIN_ORIGINAL. CROP_PROPOSED is technical pending only. After real native render/render-global pending PNG, invoke v2_native_entry bind-frame ORIGINAL LINEAGE.json FRAME_DECISION.json PENDING_RECEIPT.json FRAME_PLAN.json; it checks actual parent PNG bytes, hash and source. Then existing v2_native_entry reframe ORIGINAL LINEAGE.json PENDING.png PENDING_RECEIPT.json FRAME_PLAN.json CROPPED.png CROPPED_RECEIPT.json independently checks crop pixel equality, original ICC, output identity, and no overwrite. Do normal-size and source-matched 1:1 visual review. Every stage remains photographic_quality_accepted=false and formal_V1_registered=false.

No synthetic pixels, private photo publication, automatic subject inference, provider raw-mask verification, user iPhone saving, formal V1, or production host validation is performed by these preflight actions.
