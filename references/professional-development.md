## 形成精简风格简报

查看当前实际原片，先写关系再定参数。内部每张保留以下内容，复用同任务已有记录，默认不向用户展开。

| 字段 | 内容 |
| --- | --- |
| intent | 有依据的用途、主体及表达目的 |
| capture | 光照方向、软硬、自然/混合光与曝光、噪声等实际限制 |
| tone | 主体/背景明度关系、黑白锚点与保留层次 |
| palette | 环境色、重点色、冷暖及中性材质中的真实光源色 |
| finish | 风格强度、交付尺寸、材质肤色纹理 |
| preserve | 身份、文字、几何、光照天气、反射及构图取舍 |
| route | MATCHED、PARTIAL或PROFESSIONAL_FALLBACK，实际参考及适用范围 |

依据主体、光照、材质和用途选择明亮、柔和、低调或冷暖分离等表达；不把固定压暗、去色、颗粒或美白当改善。参考只支持其可核验关系，无有效参考时独立设计，案例数量不构成门槛。

## 选择实际执行路线

按选定表达选择实际可用原生或创意生成路线，确认能读取、修改与导出的内容；一次选择路线，只发现该路线实际需要的工具参数。Lightroom/Camera Raw可用时读取实际设置，在可回退副本或授权对象上操作并查看真实输出。darktable/photo-xmp仅在实际可用且获授权时使用，按其引擎语义设计；不把Lightroom滑块、曲线、蒙版等同其他引擎参数。

JPEG依据实际像素、ICC及可恢复细节直接处理，不要求补RAW。RAW最终色彩依据同一RAW经已知解码器和配置的真实渲染；相机JPEG只辅助选片和构图。

能力部分缺失时完成可靠支持项，记录未执行设计；实质影响目标的限制须简短说明。没有渲染器则明确未完成，不把配方称成片。本方法不要求安装软件、配置MCP、上传到新第三方或增加选风格与最终批准阶段。

## 组织处理职责

1. 确定取景、方向与必要透视后定位蒙版；只针对确有影响的噪声、镜头或雾霾问题处理。
2. 校正实际曝光与不需要的光源偏色，保留合理暖灯、真实反射与天气。
3. 建立主体可读性、亮部纹理、黑色边界与空间深度。
4. 保护肤色和材质，区分有意光源色与不需要的偏色。
5. 围绕环境色与重点色调色；同色相不等于同对象，必要时先空间限定。
6. 影调和色彩稳定后按需精修，保留自然纹理和可信锐化边缘。

这是职责划分，不要求分六次导出。普通照片完成协调初稿后实际渲染一次；复杂问题可分有界小步。遵守工具要求的预览，不用单滑块轮数或大量猜改代替摄影判断。无需调整项保持原值或不应用。

## 渲染、针对修正与终检

普通书画题字对照原图可见内容，不默认逐笔认证；保留原本模糊处，发现实际改字、增删或变形才针对修正。详见快速工作流的保护取舍。

长期保留“去AI味”：检查光影/空间自洽、可信材质和原生细节，修正假纹理、涂抹感、光晕及结构/文字变形。并入现有实际视觉终检与逐目标闭环，不凭提示词或配置宣称通过；创作强度和工具选择仍自由。

保留实际原片/技术基线、配方与输出关系。在交付尺寸判断表达和主体/环境关系，在实际原生分辨率检查受影响的肤色、材质、细字、渐变、裁切和蒙版边缘。放大低分辨率预览不能证明原生细节质量。

先记录可见问题、原因判断和针对修正，保留成功部分。每个命名目标单独或显式组选择并逐一核验蒙版；每个原始问题必须以当前输出哈希绑定的corrected或not_needed证据关闭；无需处理也须给出可观察理由，换图后重核，详见[逐目标闭环](fast-edit-workflow.md#逐目标验收)。渲染后同时复查目标及受影响品质。

| 变化 | 重新核验 |
| --- | --- |
| 几何 | 坐标、蒙版、构图及相关测量 |
| 技术白平衡/色彩 | 肤色、材质、创意调色 |
| 较大影调 | 高光、颜色、参数蒙版 |
| 降噪/尺寸 | 当前实际原生细节 |

目标满足、执行已核实、每个问题均有当前证据且终检完成时结束；无固定候选数或迭代数，不为包装重渲染。`blocked` 保留限制，不能标 `ACCEPTED`，未执行局部修饰或未做Lightroom导入不能写成通过。

内部记录保留来源、简报、路线、参考、能力、基线、配方/执行子集、输出、逐目标问题与蒙版证据、未执行项、验收、时间及哈希。标明MEASURED、INFERRED、DESIGNED；只有实际执行项为APPLIED。计时与保存规则见快速工作流。

## 成组一致性

按光照分组，用已有认可成片或本任务完成的代表图作固定基准。统一主体表现、材质身份、环境/重点色关系及风格强度，允许日光、树荫、混合光有合理差异。每张直接对照固定基准，避免相邻图逐张漂移。

只同步明确且有依据的字段；曝光、白平衡、裁切、降噪、配置文件和蒙版逐张复核。遵守工具并发限制，批量规划最多两张并发，相同配方才批量渲染。每张验收后即可交付，无须等整组报告或额外普通调色批准。
