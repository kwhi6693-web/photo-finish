# 个人风格与场景适配

现行全流程创作自由见[创作指导](creative-direction.md)及主规范：专业判断主导每张照片，旧风格与原光色是可选素材；本页的技术/保真检查不构成保守微调、自然色或全局处理范围。
从SKILL.md所指当前主规范、已核验会话摘要及完整配置加载规则。明确收藏授权的 `STYLE_REFERENCE` 才写入私有风格库；长期全局规则仅在用户明确要求保存时更新。`EDIT_TARGET`、`ANALYSIS` 和成片不自动收藏，也不自动改写长期审美。历史Pinterest案例不作默认风格。

先看当前原片、读取适用的可选全局指令，再由 prepare 检索私有库，实际查看并取舍候选后才在 submit 锁定最终方向。按光照结构、场景、主体、材质、色彩、影调和表达目的判断参考；不重扫全库，不设固定张数。存在有效参考选 `MATCHED`；部分支持选 `PARTIAL`，只转译有证据的关系；证据不足或不适用选 `PROFESSIONAL_FALLBACK`，按原片专业判断直接设计，无需停工或重新选风格。用户明确指定的 ID、关键词或分组缺失/全部不可用时，说明具体问题，不默默切换风格。

按[专业后期](professional-development.md)形成简报后，适用时选CORE、一个主场景、有界条件与单张修正；独立专业分支可另设计配方。雨天、玻璃与高反差按选定表达设计，必要保护继续核验；多种技法可以结合，实际顺序与结果须协调。按实际曝光、主体亮度和光源决定明度与白平衡，分清RAW Kelvin与JPEG滑块；按表达选择影调与色彩；有意的时刻/天气氛围演绎按创意改动记录，不冒充实际拍摄条件。

反射、玻璃雾感、环境色和光源色均先判断是否削弱当前照片。可克制干扰或偏色，但不默认清除全部反射、去尽雾霾或中和真实暖光；保留有叙事作用的天气、材质与空间线索。

实际路线需要完整参数设计时，按需记录BASIC、WB、RGB/通道曲线、八色HSL、分级、校准、质感、颗粒/暗角、锐化/降噪、必要镜头修正及蒙版区域/顺序。配置支持项用现行值，独立设计标DESIGNED并记录原因；无需调整项保持原值或不应用。将完整Lightroom设计与实际原生执行子集、未执行项分开，未导入或未渲染不得称全部通过。

创作新风格已获授权；只有明确要求Pinterest检索或比较时才强制展开这些专项资料；按用户数量与用途执行，来源缺失如实说明，不伪造链接或测量。任务风格不自动改长期核心，结果不自动入参考库。

默认交付最终成片及简短版本/保存状态，新成片首次交付一行可选返工提示（批量末尾统一一次），不附原片、对比或调整说明；详细参数、参考和过程按需提供，内部记录遵循[快速工作流](fast-edit-workflow.md)。
