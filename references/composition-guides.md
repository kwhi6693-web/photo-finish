# 构图规则 v2.0：由表达主导

现行全流程创作自由见[创作指导](creative-direction.md)及主规范：专业判断主导每张照片，旧风格与原光色是可选素材；本页的技术/保真检查不构成保守微调、自然色或全局处理范围。
修订：2026-10-21.4。用户指令：“重构此条构图规则，解放构图边界”。本规则替代以“原构图先合格则保留、否则才允许改动”为前提的旧解释。

> **以最终视觉表达为目标，主动选择最有力量的构图；可自由保留、优化或重构原片，不以原取景、原主体位置、完整性、画幅或改动幅度作为默认边界。**

## 自主决策

每张先明确想让观看者看见什么、感到什么，再从主体尺度、注意力、留白、节奏、光影和空间组织选择构图。原构图已经合格，仍可选择表达更强的重构；原构图最有效则主动保留。不必先证明它有缺陷，也不要求每张必须改变。

| 结论 | 执行 |
| --- | --- |
| PRESERVE｜保留 | 原取景在实际比较中最有效，直接采用 |
| OPTIMIZE｜优化 | 自主调整裁切、方向、比例、旋转与透视，幅度由表达需要决定 |
| REFRAME｜重构 | 重新确定视觉主体、局部取景、画面比例及重心，允许大幅裁切、横竖转换和抽象化表达 |

三种结论同等可选，不设轻裁优先、固定裁切上限、保留像素百分比、完整全身/完整建筑或统一平台比例要求。可以舍弃非关键环境、原主体的部分轮廓或原有留白，按实际效果与输出可用性承担取舍。真实保留像素仍须记录，不用放大后的尺寸冒充原生细节。

## 创意构图路线

为构图带来明确收益时，允许必要的画布扩展、非关键干扰清理和非核心元素整理，无需为本范围内的普通编辑逐轮确认。选择实际可用工具；内容生成、清理或重排时读取相应图像技能，引用实际原片并复核输出。生成操作不是每张必做，也不强制产出多款。

保留可识别主体身份、作品题字与印章、产品关键信息及事件事实；改变这些信息须有当次明确创作意图。纪实、证据与档案照片服从其真实性用途。内部明确生成、移除与重排范围，不将补出的内容描述为现场事实。拍摄原片及授权参考保持原样。

## 实施与验收

1. 设定表达目标，按需比较原取景及有希望的新取景，选择一个推荐结果。审美判断由实际看图的助手完成，数值引擎不代替判断。
2. 在副本上实际执行，记录真实裁切、旋转、透视、画幅及内容改动范围。所需操作不可用时完成可行路线并说明实质限制，不能把方案称为成片。
3. 复核主体识别、文字信息、材质、几何、光影、接缝及输出质量；裁切或生成后重新核对有效画面测量、参考适配和蒙版。未执行的改动不算验证通过。
4. 默认逐张只交付最终成片，不附原片、对比或调整说明。技术参数、方案对比和取舍记录内部保留，按用户需求提供。

## 项目来源

构图权威来源为`10_SYSTEM_CONFIG/composition_policy.json`。会话摘要与规划器必须加载该文件并核验摘要；冻结色彩配置中旧构图对象只作历史兼容快照。构图规则独立升级为2.0，数值运行时1.5.0、色彩配置1.3.1、核心1.0.0、预设与授权参考不变。
