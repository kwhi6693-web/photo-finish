# 可选风格与质感目录

修订2026-11-03.3。此目录提供 Photo Finish 自己的摄影意图定义与调用约定，借用 Apple 风格名称作为参考；不是 Apple LUT、私有算法、参数包或原生摄影风格元数据。下表的影调/色彩目标是本项目的设计，不声称苹果的精确机制。所有条目初始为 DESIGNED，尚无本修订实图验收；当次工具可执行性与真实输出须另行验证。官方未公布18 Pro完整逐项清单，16项名称由既有代际清单与新增珠光资料整理，不能称已逐项实机核对。

## 使用与记录

- 默认为每张原片自主选择最有表达力的方向，先由原片得出视觉目标，再按需要查询少量对应条目；允许部分转译或独立设计，目录不是审美边界。自动选择不继承“保持构图/只调色”的示例约束，也不强制套名、改构图或渲染多个候选。
- 只在用户指定风格/质感，或本片摄影方向确有需要时读取目录；同任务复用。按名称/别名定位对应行及公共约束，不遍历或试渲染全部条目；自主判断可不采用目录。恢复/比较/资产管理不读取目录。
- 区分 `photo.*` 摄影风格参考与 `filter.*` 传统滤镜参考。同名“鲜明”“反差色”若用户未指明类别：按当前谈论类别；上下文无类别时采用 photo 同名，在内部记录所用类别，成功交付不额外附文，也不额外追问；用户明确传统滤镜则只用 filter。黑白/冷暖泛称由本片意图选择，不虚构用户指定。
- 一次基础只选一个 style_id（或独立专业设计）；质感选 none/glow/film 之一，grain 选 off/on。这是执行规划表示，不是 photo_edit 或外部工具的新参数；绝不把这些自定义键直接塞入现有工具调用。
- 在已有 task_instructions / direction.intent 或 light_material 中记录类别、style_id、选定视觉目标、强度意图、texture 与 grain；qa_focus 写原片到目标的可观察变化及保护。兼容字段无需新增控制器阶段。原片/参考选择仍走既有 prepare/select，不把目录条目伪造为私人收藏 ID 或已看过的参考图。
- 风格强度只表示轻/中/强的目标表达，数值由实际原片和当前引擎定义，不转译成虚构的 Apple 0–100 刻度，不照搬其他软件参数。不同场景允许不同参数；强度不自动改变曝光或构图。
- 本目录不能覆盖当前要求、长期规则、参考用途限制或内容保护。指定“保持构图/只调色”必须保护几何、禁止扩图清理与物体重排；是否冲突按具体约束判断：保持构图只限制几何，不禁止已明确要求的黑白/颗粒；要求保留原色时黑白冲突，要求纯光色调整且未允许质感时不擅加颗粒。冲突先按明确当次意图解决，不默默增加。风格指定只决定视觉方向，不授权新工具、内容生成、保存、长期收藏或外部发布。

## 摄影风格参考（16项）

这里为非人像场景设计，底色不执行肤色分析或美化。标准表示不附加风格偏置，仍可为真实缺陷作必要校正；“完全原样”要求则不编辑。

|---|---|---|---|---|
| photo.standard | 标准 Standard | 忠实现场色彩和自然明暗，不强加色偏 | 仅必要曝光/白平衡/层次校正 | 通用；已充分则不编辑，不为风格名强造变化 |

| photo.neutral | 中性 Neutral | 冷暖平衡、材质本色与清晰中间调 | 校正色偏，按光源保留合理冷暖差 | 建筑、产品、甜品；不把所有灯光强行变白 |

## 质感与颗粒

| ID | 目标定义 | 能力要求与失败条件 |
|---|---|---|
| texture.none | 保留原生质感，不附加光晕或胶片效果 | 不代表自动消除已烘焙效果；恢复须有准确父版本/原件 |
| texture.glow | 亮部和光源的柔和辉光，暗部和关键边缘保持可辨 | 需要真实可控高光辉光/局部混合能力；单独拉亮、降对比或全幅模糊不算实现；防HDR白边和光源扩散失真 |
| texture.film | 胶片参考的亮部过渡、适度柔化数字锐利感及受控边缘晕染 | 需要对应真实工具及内容保护；不等同暖棕、去饱和、颗粒或失焦；不宣称某款胶片精确模拟 |
| grain.off | 不新增颗粒 | 不授权去噪；已有颗粒不声称无损移除 |
| grain.on | 添加均匀可信、尺度适合输出的摄影颗粒 | 需要真实颗粒工具与正式输出；不得虚构参数、增添物体斑点或以色噪冒充；放大检查文字/食品/天空，记录实际工具参数 |

柔肤 Soft Skin 明确范围外，不提供人像美化；不以“引入18Pro功能”绕过非人像定位。

## 工具映射与接受门槛

色彩/影调目标通过当前真实授权工具的 exposure/highlights/lights/darks/shadows、brightness/contrast、温度/色偏、HSL、vibrance/saturation、真实B&W等能力选择性实现；不是要求填完所有参数。Adobe image_apply_adjustments 若采用温度须 tempA/tempB/tempLuminance 成组，HSL须其三个字段成组，通道饱和须 channelTarget/channelSaturation 成组，范围及单位按当次实际接口，不套苹果滑块。黑白须真实去色后验证残余颜色与灰阶，不把工具名称当已执行证明。

工具的强制预览、单图交互/代做路由、STOP、PNG输出、局部mask规则按现行原生路线，不因风格名改变。当前接口核查（仅接口证据，不是出图验收）：

- **颗粒**：Adobe image_apply_effects 有真实 `options={effect:"grain",grainAmount:...}`，grainAmount范围0–100；这是该引擎参数，非Apple刻度。单图默认走 interactive_image_apply_effects_app，`effectIds=["grain"]` 只用默认值，不能声称设置数值；该交互工具调用后STOP，无正式URL即仅预览。明确代做/工具输入中间结果等符合工具例外时可用服务端，PNG正式输出沿 returned/review/保存协议。必须先核验最新输入，不把图像引用或上游版本搞错；现有局部修订白名单仍适用，不因工具有mask字段绕过控制器限制。多步额外调用仅请求确需颗粒时增加，不强制所有风格加颗粒。
- **光晕**：交互式效果有真实 `bloom`，仅默认值、调用后STOP；记录为光晕近似预览，不说已取得正式文件。当前 image_apply_effects 服务端枚举没有 bloom，不能自行传入。若用户要求直接正式交付光晕但没有可取得正式字节且获准的对应路线，说明阻塞，不用全幅高斯模糊或生成绕过。
- **胶片**：image_list_presets / image_apply_preset 存在真实Lightroom预设路线；只有确需评估预设时才列出当前精确名称，不默认日常全量读取。预设是完整光色/颗粒/锐化组合，不是独立质感；不能把任意film/vintage预设称Apple Film或与已选安静/金色等效果等价。若该完整预设符合用户明确允许的整体意图才采用，记录差异、完整参数及真实名称，单一输出只用一个完整预设，不在已烘焙预设上再叠预设；遵守强制显示/STOP与正式输出要求。尚无独立胶片质感的正式可控路线时保持受限，不静默用完整预设替换指定组合。

不得把glow/film/grain自造字段传入 image_apply_adjustments，也不以曝光/饱和冒充质感。未来接口变化先核查真实能力与保护，再验证当次任务。禁止为模拟效果另写像素编辑脚本，或为绕过原生工具限制默认全幅生成。

用户明确要求的质感/颗粒缺能力时，编辑前说明具体阻塞，不静默丢弃该部分后宣称整项通过；用户已明确允许只完成可支持部分时按该范围继续。自动选择只用可支持部分，无需额外权限提问；不将未执行效果记 APPLIED。整个目标能安全完成时沿原流程执行，否则保留未通过；不把“支持基础调色”说成“支持全部25种效果”。

在原有 review.note 对照选定目标记录实际变化、保留价值、色偏/灰阶/光晕/颗粒风险及未实现项；同源原片、正式文件、保护与保存门槛不变。状态分开：DESIGNED＝有定义；本次能力核查＝仅接口证据；APPLIED＝对应效果确已实际执行并取得正式输出，仅同任务基础调色返回文件不能把未执行的film/glow/grain标APPLIED；本次视觉通过＝实际比较符合目标；持久保存＝真实回执。没有本修订实图样本前不写通用通过率、风格已验收或苹果一致性结论。
