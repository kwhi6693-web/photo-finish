# 按需原创文案

只在用户明确要求文案时加载；语言、数量、长度和语气按当次要求，不为普通修图自动生成。下述八组结构仅用于明确要求完整双平台含文案包的兼容格式，不是所有九宫格的默认条件。

## 先建立事实边界

只使用成片中可见的信息，以及用户明确提供的地点、日期、人物关系、品牌和拍摄经历。信息未提供就省略，不猜测、不暗示；始终做到“不虚构事实”。不要复制或改写现有平台文案、歌曲、诗歌、书籍或其他作品，也不要用参考作品的标志性句式。

## 独立写八组文案

在用户明确要求完整双平台含八组文案包时，提供四组中文与四组英文，并按以下四种命名方向各写一组：

1. 极简留白：短句、克制、允许语义留白。
2. 电影诗意：用成片中真实可见的光线、动作或空间建立镜头感，不借用歌词或诗句。
3. 生活叙事：围绕用户已经确认的真实经历与细节组织自然叙述。
4. 冷感编辑：使用简洁、客观、具版面感的表达，不虚构品牌或拍摄设定。

中文和英文必须分别独立创作，不做逐句翻译，也不先写一种语言再逐句改写另一种语言。让两种语言各自符合其自然语感，同时表达同一组照片能够支持的事实与情绪。默认不使用 Emoji。

## 写两组标签

提供两组标签，每组五至八个 Instagram hashtags。第一组强调题材与可见内容，第二组强调真实的氛围、色彩或摄影类别。只使用能由照片或用户事实支持的标签；不加入虚构地点、活动、品牌、身份或摄影师姓名。

## 使用校验器兼容标题

在 `captions.md` 中只用下列编号标题形态；编号不得缺失、重复或超出范围：

```markdown
# 中文文案 1
（极简留白文案）

# 中文文案 2
（电影诗意文案）

# 中文文案 3
（生活叙事文案）

# 中文文案 4
（冷感编辑文案）

# English Caption 1
(Minimal copy)

# English Caption 2
(Cinematic copy)

# English Caption 3
(Lifestyle narrative)

# English Caption 4
(Cool editorial copy)

# Hashtag Set 1
#tag1 #tag2 #tag3 #tag4 #tag5

# Hashtag Set 2
#tag1 #tag2 #tag3 #tag4 #tag5
```

交付前确认：四组中文、四组英文、两组标签全部存在；四个方向各自可辨；中英文不是互译；每组标签为五至八个；所有事实可追溯；没有复制受保护文本。
