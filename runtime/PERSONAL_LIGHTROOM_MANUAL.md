# Lightroom按需操作与历史配方

现行编排2026-10-23.4；日常照片先读[总规范](我的照片美化偏好与修图标准.md)，API按需见[执行接口](10_SYSTEM_CONFIG/DELIVERY_ADAPTER.md)。本手册只在实际使用Lightroom、查看旧参数或用户索取完整设计时读取。

专业判断决定构图、光色与强度，保留/优化/重构同等可选；旧预设为素材，不是审美上限。先锁定身份、题字/印章等保护条件，按真实可用能力选路线；书画题字按与原图可见内容一致验收，原本难辨保持，不默认逐笔认证；实际改字、增删或明显变形须修正。先查询适用参考短名单并记录取舍，无适用关系或不可访问则如实专业回退。

实际使用Lightroom时，保留原片并在副本处理，记录软件、配置/相机解码器、实际参数及蒙版。JPEG直接处理，RAW看同一RAW的真实解码输出；其他引擎数值不视为等价。选择所需几何、技术校正、明暗组织、色彩和局部精修职责，顺序按依赖决定，不强制六次导出。按表达判断高光/黑位、色彩与纹理，不机械套固定幅度。

长期保留“去AI味”：检查光影/空间自洽、可信材质和原生细节，修正假纹理、涂抹感、光晕及结构/文字变形。并入现有实际视觉终检与逐目标闭环，不凭提示词或配置宣称通过；创作强度和工具选择仍自由。

实际查看输入、预览和最终全幅及原生细节，检查保护对象、蒙版边缘与真实色彩声明。所有问题（含not_needed）与保护目标绑定当前输出；contract 3在验收时重核当前政策/总规范上下文，旧任务过期则新建并复核，不改变历史记录。文件改变后重检；未知或限制不写成通过。已知源空间才实际转换，未标记生成图的普通分享假设不能冒充专业标定。

普通EDIT保留真实路线精简记录，默认逐张仅输出最终成片，不附原片、对比或调整说明。完整82项DESIGNED参数、CSV及对比仅按需或历史Lightroom研究兼容，不是每张交付条件。旧预设、参数定义及XMP位于06_SCENE_PRESETS和10_SYSTEM_CONFIG/style_config.json；未声称已完成Adobe实际导入或82项全渲染验证。

专业视觉意图/光线材质优先于候选色彩距离，多步编辑用direction/next-render保留原片与当步来源；全幅及受影响细节实际复核。完整接口按需见PROFESSIONAL_WORKFLOW.md（技能内professional-workflow.md）。

默认把画面表达做得明显更充分：主动完成构图、主次光影、色彩与材质；去AI味和题字一致不等于保守微调。终检须实际比较表达目标与结果，技术通过不能替代表达完成。未落实的表达关系继续针对性修正；不机械套暖金/高饱和，也不强制每片大改。
