# 全流程创作自由规则

现行创作方向2026-10-26.3；保留创作授权与摄影质感要求。依据用户“解放所有边界”。专业摄影与艺术指导对每张照片主动决策；MATCHED、PARTIAL与PROFESSIONAL_FALLBACK只描述参考证据，所有分支都可独立设计风格。

允许自由选择构图、画幅、视觉主体、明暗主次、局部塑光、光线重塑、冷暖、色相、饱和度、黑白、颗粒、光晕、虚实、材质风格化和精修强度；原图合格也可重新表达。旧Style DNA、自然色、原光线/天气与历史预设都作为素材，不构成审美上限。按表达和实际能力选工具，不默认限制在全局滑块或保守微调。

创意照片可采用必要扩图、非关键干扰清理、背景/氛围整理与非核心重排；光照、天气、日夜氛围演绎明确记作创意处理，生成编辑按相应技能引用原片。保留原文件、可识别身份、关键文字印章与产品信息；改变身份或关键事实需当次明确相应意图。纪实、证据和档案按其真实性要求处理，不把创意演绎当作现场事实。

每张检查表达、构图、主次光影、色彩与材质细节，选择最有效的处理范围。允许主动保留，也允许大幅重塑；变化幅度不是质量指标。实际输出、原生细节、ICC与来源链继续核验，高光/深黑/颗粒等结合有意表达判断，不仅凭固定阈值判定。默认交付最终成片及简短版本/保存状态，新成片首次交付一行可选返工提示（批量末尾统一一次），不附原片、对比或调整说明；主规范只加载一次，详细指南按需读，不新增选择或批准阶段。

长期保留“去AI味”：检查光影/空间自洽、可信材质和原生细节，修正假纹理、涂抹感、光晕及结构/文字变形。并入现有实际视觉终检与逐目标闭环，不凭提示词或配置宣称通过；创作强度和工具选择仍自由。创作自由不能自动覆盖本质量要求；明确非摄影媒介按当次意图评价并保留真实来源。

书画、题字与印章默认以“与原图可见内容一致”为准：保留内容、字形/笔触关系、印章和画作布局，原本模糊难辨的地方保持，不猜写或补清。允许所需光影与调色。仅因无法独立辨读、未逐笔鉴定，不判失败；不额外做每字释读、作者/真伪考证或像素级认证。实际改字、增删或明显变形/重绘改变可见内容，仍须修正。普通后期在渲染前用semantic_identity落实此要求；只有当次明确逐笔/像素级要求或严格档案用途才选exact_content，不自行在提示词升级条件。

机器权威：runtime_policy.json#/photographic_naturalness_policy与runtime_policy.json#/creative_direction_policy；其源哈希参与现有SESSION_BRIEF核验。旧数值和参考不被重写，其审美限制由本规则覆盖。

专业视觉意图/光线材质优先于候选色彩距离，多步编辑用direction/next-render保留原片与当步来源；全幅及受影响细节实际复核。完整接口按需见PROFESSIONAL_WORKFLOW.md（技能内professional-workflow.md）。

灰闷、反差、色彩克制与主体层级的诊断和适用边界见[明暗与色彩理论](TONE_COLOR_FOUNDATIONS.md)。低饱和＋高对比仅是可选表达，不覆盖当次指令、长期偏好或参考用途限制；不统一压暗、去色或抹去薄雾。

默认把画面表达做得明显更充分：主动完成构图、主次光影、色彩与材质；去AI味和题字一致不等于保守微调。终检须实际比较表达目标与结果，技术通过不能替代表达完成。未落实的表达关系继续针对性修正；不机械套暖金/高饱和，也不强制每片大改。
