# 明暗、色彩与视觉层级：美化判断依据

用途：在实际查看原片和拟用参考后，为最终方向、光色处理与实际终检提供依据。遇到灰闷、色彩嘈杂、主体不突出或希望克制色彩时读本页；不是统一预设，也不增加日常调用或用户批准阶段。

## 概念与专业依据

Adobe 官方说明区分整体色彩强度、对低饱和颜色作用较大的 Vibrance、局部反差 Clarity 与影调曲线，并用直方图辅助观察分布和剪切。[1] 因此不能把“降低饱和度”“去灰”“加清晰度”视为同一操作。

Adobe 的影调说明将中间调反差与白黑端点控制分开，指出控制之间会相互影响、设置须随照片和光照调整，雾景可避免强制白黑剪切。[2] 局部蒙版允许在实际选区调整曝光、反差与色彩，并控制边缘过渡。[3]

下列诊断、审美取舍及案例是本技能据这些工具机制和视频观点作出的应用推导；官方文档说明工具作用，不为某种审美背书。

| 概念 | 判断用途 | 避免混淆 |
|---|---|---|
| 明暗关系 | 主体、邻近背景、亮部与暗部如何组织 | 日常“明度”不自动等同实测 Lab L*、线性亮度或正确曝光；没有测量不填写数值 |
| 整体影调范围 | 明暗端点、主调与中间调的分布 | 宽直方图不保证好看；低调、高调、薄雾与柔和表达可合理集中 |
| 局部明暗分离 | 特定主体与背景、材质转折的可读性 | 全图范围宽仍可能主次混乱；全局加反差可能先损坏其他区域 |
| 色彩强度与关系 | 环境色、重点色、肤色及材质色是否协调 | 低饱和不等于少色相、灰片或统一偏棕；鲜艳也可有清楚层级 |
| 清晰度与锐化 | 局部结构、边缘和真实细节是否合适 | 不以 Clarity、去雾或锐化代替影调设计；过强会制造硬边、光晕和粗糙感 |

把色彩克制与明暗组织作为两个设计维度分别判断，同时在实际结果中检查它们的相互影响。对比提高可能伴随颜色观感变化；饱和度降低也可能削弱靠颜色区分的主体。不能只看某一个滑块的数字。

## 从原因到操作

1. **确认意图和依据。**先遵守当次指令、长期规则与偏好，实际查看参考后再定最终方向。没有约束的部分专业自主判断；本页方法位于通用默认层，不覆盖用户意图、参考用途限制或已锁定保护。
2. **辨认灰闷的原因。**看主体与邻近背景、光线方向、材质转折和色彩竞争。主体与邻近背景明暗接近且难分时，可优先考虑明暗分离；其他情况下也可按表达目的塑造光影，不将它限为缺陷修复；若是实际雾气、眩光、不需要的偏色、失焦或噪声，按实际原因处理，不许用反差宣称恢复不存在的细节。
3. **选择分离手段。**可用明暗、冷暖、色彩强弱、虚实、位置、留白或局部清理建立主次。主体可比背景暗，也可保留叙事所需的多主体；“突出一个”是简化提示，不是排除其他构图的硬约束。
4. **决定范围。**全图确需重建关系时才选全局影调；只在局部拥挤时用真实可用的局部控制。已有高光紧张或深暗细节重要时，优先保留必要层次，避免用全局拉反差伤及无关区域。明确选择剪影或高光溢出等表达时，按意图和保护要求复核。
5. **设计色彩。**色彩杂乱时可压低非重点颜色或整体强度，再保留重点色；也可不降饱和。鲜艳夜景、花卉、节庆与用户明确偏好依本片设计；肤色、食物与产品关键颜色单独核对。
6. **实际输出后验证。**看层级是否更清楚、氛围是否传达，以及调整的代价；保留成功部分，只修真正的问题。不为了让直方图铺满、滑块达到某数值或变化足够大而继续处理。

## 参考迁移与现有接口

实际比较参考中的主体/背景关系、明暗过渡、重点色和环境色。迁移的是适用关系，不是复制直方图、曝光值或软件配方。同场景不保证同光线，低饱和参考也不要求待修图低曝光。

参考的 `use_for` 和本次 `uses` 继续限定借鉴范围：只允许 `color` 时仅借鉴色彩关系，不据此复制参考的明暗或构图；待修图自身需要的独立光影设计可由专业判断提出，说明其来源。只允许 `light` 时不顺带照搬参考色调。每项依据在既有选择理由中写清，不新增字段或调用。

把决策放进现有 `submit.direction`，只写本次必要的关系：

| 既有字段 | 本页如何帮助填写 |
|---|---|
| `intent` | 本片希望传达的情绪、用途和主体；不只写“高级感” |
| `hierarchy` | 主体与哪些邻近区域应有何种区别，以及保留哪些次要关系 |
| `light_material` | 光线和材质转折如何呈现，必要亮暗细节如何保留，色彩强度如何配合 |
| `output_use` / `route` | 按实际屏幕/打印用途和真实可用的 native、creative 或 hybrid 路线选择 |
| `qa_focus` | 本次易受影响的高光、暗部、肤色、重点色、材质和过渡区域 |

原生路线只使用已确认软件真实支持的参数、曲线和蒙版；示例数值不跨引擎直接搬运。生成路线描述可观察的目标关系，引用真实原片和已选择的参考，不把“−20/+15”或提示词宣称为已执行参数。保护、真实来源和逐目标闭环继续有效。

## 场景推演

以下是描述性案例，不是已处理照片或质量实验。

| 场景 | 方向选择 | 实际终检重点 |
|---|---|---|
| 浅色杯子贴近浅色背景，杯口高光已紧张 | 先分开杯身轮廓与局部背景，依可用信息保留杯口；颜色本已协调时无需全局降饱和 | 杯口必要纹理、陶瓷渐变、轮廓和蒙版边缘，无光晕或假裂纹 |
| 清晨薄雾，用户要求柔和 | 保留有意的窄影调和远近消隐；只在需要时轻分开近景，不强行去雾或撑满直方图 | 雾的连续层次与主体可读性，没有硬边、脏暗部或失去空气感 |
| 用户要求鲜艳夜市，脸部被灯牌淹没 | 保留鲜艳情绪，按局部光色和空间关系突出人物，不自动执行低饱和公式 | 面部与灯牌层级、合理混合色温、招牌文字、单通道剪切与肤色 |
| 高调人像或剪影 | 依意图保留浅亮主调或深暗主体，以边缘、背景和姿态组织关系 | 不因主体不是最亮或直方图集中判失败；身份和需要保留的细节仍符合要求 |

## 实际终检与证据

在现有全幅检查中判断情绪、主次与色彩；在本次受影响的原生细节中看高光/暗部、肤色、渐变、噪声、边缘和蒙版过渡。需要时可用已有直方图、通道剪切或内部灰度预览辅助，但不强制新增工具调用或导出，也不以灰度替代彩色结果检查。未实际获取的数据保持未知，测量与审美判断分开。

质量通过要求与本片方向相符并有实际看图依据；不要求每张都去色、拉反差、压暗、消雾或制造纹理。默认仍逐张仅交最终成片，分析、参数和依据留在内部，用户要求分析时再展开。
